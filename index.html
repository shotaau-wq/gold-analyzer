ntfyアプリを入れ、GitHubのSecretsに TWELVE_DATA_API_KEY と NTFY_TOPIC を登録します。通知用ワークフローは別ファイルで追加します。

GitHub Actionsの定期実行は遅延・停止することがあり、5分足の確定直後や秒単位の通知は保証できません。API無料枠も確認してください。

注意：これは価格データに基づくルール分析で、生成AIによる将来価格の予知ではありません。XAU/USD参考価格とXSの約定価格には差があります。価格が古い・APIが失敗・履歴不足のときは数値を作らず保留します。
